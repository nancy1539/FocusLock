# FocusLock - For Better Focus

FocusLock is an educational Android app designed to help teachers, students, and individuals stay focused during study and work.

## 🎯 Aim
To reduce distractions and create a disciplined digital environment for learning and personal growth.

## 👩‍🏫 For Teachers
- Start a Focus Session for the whole class
- Monitor student focus time
- Block distracting apps during lecture/class
- Send focus reminders to students

## 👨‍🎓 For Students
- Join teacher's focus session
- Stay away from Instagram, Games, etc. during study
- Track your daily focus hours and productivity
- Get motivated with streaks & reports

## 👤 For Personal Use
- Personal Focus Mode for self-study / work from home
- Custom timer - set your own focus hours
- Block selected apps that distract you
- Personal progress report & daily streaks

## ✨ Key Features
- Teacher, Student & Personal Mode
- Live Focus Session
- Smart App Blocking
- Daily Focus Report & Analytics
- Simple, Clean & Student-Friendly UI

## 📥 Download
Go to Releases > Download `FocusLock.apk` and install on Android.
